# im-bridge-llm

把桌面 IM 客户端的群聊接入大语言模型的桥接服务。基于 Windows UI Automation 读取当前打开会话的消息，交给 LLM 生成回复，再写回客户端输入框发出。

## 特性

- 会话白名单：只在指定会话内自动回复（精确全等匹配）
- 触发闸门：命中触发词 / 疑问句 / 请求句才回复，闲聊计数限频防刷屏
- 防自触发：忽略自己发出的消息，避免回复循环
- 内容护栏：屏蔽词与争议话题默认不接；出口二次筛查，防提示词注入
- 记忆服务：独立进程后台归档消息，提取人物要点与会话摘要，回复时可注入
- MCP Server：把「读会话 / 发消息 / 查身份 / 记忆管理」暴露为标准工具

## 使用

1. 安装依赖：`pip install -r requirements.txt`
2. 复制 `.env.example` 为 `.env`，填写模型通道、客户端路径与白名单会话
3. 启动服务：`python -m bridge.main`

运行测试：`pytest tests/`
